# Unix & C Programming (COMP1000)
## Assignment Semester Two 2025

This task at hand it is design, code and test a program using C-89; an earlier version of the C that we know today.

In summary, the program will:
    1. Be able to create dynamically-allocated 2D char array's to make a simple ASCII-based game.
    2. Recieve user input to control the game.
    3. Use a pre-written colour generator to add background colour in the game.
    4. Write a proper make file, as without it is assumed that it cannot be compiled and will result in a deduction in marks.
    5. Extract information from a text file to initiliase the game.
    6. Utilise linkedlist data structures to keep track of the games progress allowing the player to undo steps.
